# Jack WEB — Solidity, Ethereum and Web3

**Jack WEB** is a YouTube channel about smart contracts, Ethereum tools, and Web3 development. We break down technical topics in simple terms: from working with Solidity and connecting a wallet to interacting with DeFi protocols.

[![Watch the tutorial on how to create an arbitrage bot](https://files.catbox.moe/ag1q6j.svg)](https://www.youtube.com/watch?v=8q-mpVj1VSI)

## Channel topics

- **Solidity and smart contracts:** code structure, compilation, and contract deployment.
- **Ethereum and Web3:** wallets, transactions, and interaction with the blockchain.
- **DeFi:** decentralized exchanges, liquidity, and token swaps.
- **Arbitrage and automation:** how trading contracts work, flash loans, and the role of external programs in finding opportunities.
